ALEX PORTFOLIO - VISUAL STUDIO CODE

1. Open this folder in Visual Studio Code.
2. Put your own profile photo at:
   images/profile.jpg

   If your image has another name, change this line in index.html:
   <img src="images/profile.jpg" alt="Alex">

3. Edit the name "Alex" and the text in index.html.
4. Edit your Skills, Education and Experience in their individual HTML files.
5. In contact.html, replace:
   you@example.com
   with your real email address.

NAVIGATION
Each top navigation item is a separate webpage:
Home       -> index.html
Skills     -> skills.html
Education  -> education.html
Experience -> experience.html
Contact    -> contact.html

ROTATING JOB TITLE
The Home page automatically cycles between:
Web Designer
Twitch Streamer
Developer

To change these words, open script.js and edit:
const roles = ["Web Designer", "Twitch Streamer", "Developer"];

RUNNING IT
The easiest way is to install the "Live Server" extension in VS Code.
Then right-click index.html and choose "Open with Live Server".

You can also double-click index.html to open it in a browser.
